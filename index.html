    ข้อมูลของคุณ

    ข้อมูลทั้งหมดเก็บอยู่ในเครื่อง/เบราว์เซอร์นี้เท่านั้น ไม่ถูกส่งไปที่ไหน — แนะนำให้ส่งออกสำรองเป็นระยะ และถ้าเปลี่ยนเครื่องให้นำเข้าไฟล์สำรอง

    ติดตั้งเป็นแอป

    iPhone/iPad: เปิดใน Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

    macOS Safari: เมนู ไฟล์ → เพิ่มไปยัง Dock…

    macOS Chrome/Edge: ไอคอนติดตั้งที่แถบที่อยู่ → Install
